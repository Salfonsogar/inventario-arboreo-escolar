# Inventario arbóreo escolar

Aplicación web de una sola página (HTML autocontenido) para el registro e inventario de árboles en centros escolares.

## Uso

- App publicada: https://salfonsogar.github.io/inventario-arboreo-escolar/
- Archivo principal: `index.html`

GitHub Pages sirve `index.html` desde la rama `main` (raíz del repositorio).
